# Tableau Dashboard

The interactive Cyclistic Bike-Share Analysis dashboard was created using Tableau and published on Tableau Public.

### Tableau Public

[View the Interactive Dashboard](https://public.tableau.com/views/Cyclistic_Bike_Share_Analysis_17888743797290/Dashboard1?:language=en-US&publish=yes&:display_count=n&:origin=viz_share_link)

The dashboard explores:

* Rider type distribution
* Monthly ride trends
* Weekly ride patterns
* Average ride duration
* Differences between annual members and casual riders
